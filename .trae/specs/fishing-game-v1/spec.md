# 摸鱼大师 - 钓鱼挂机游戏 v1.0 规范

## Why
制作一款纯文字挂机钓鱼游戏，适合工作摸鱼场景，支持网页版运行。

## What Changes
从头创建完整的钓鱼游戏系统，包括：

- **钓鱼系统**：自动挂机、WASD小游戏判定
- **打窝系统**：缩短上鱼时间、饵料消耗机制
- **鱼类系统**：4种大小、闪耀属性、价格机制
- **商店系统**：鱼竿和鱼饵购买
- **合成系统**：材料合成高级鱼饵
- **存档管理**：删除、导出、导入
- **图鉴系统**：记录捕获的鱼类
- **桌面通知**：上钩时提醒
- **调试模式**：URL参数开启

## Impact
- 新建项目文件：index.html, game.js, gameData.json, style.css

## ADDED Requirements

### Requirement: 钓鱼系统
游戏必须提供自动挂机钓鱼功能。

#### Scenario: 开始钓鱼
- **WHEN** 用户点击"开始钓鱼"
- **THEN** 消耗1个鱼饵（如有），设置随机上鱼时间

#### Scenario: 上鱼时间计算
- **WHEN** 鱼上钩时
- **THEN** 计算上鱼时间：鱼5-45分钟随机（期望45分钟），材料5分钟
- **AND** 如果没有鱼饵，上鱼时间翻倍

#### Scenario: 预计上鱼时间显示
- **WHEN** 钓鱼进行中
- **THEN** 每秒更新显示预计上鱼时间（分钟）

### Requirement: 钓鱼小游戏
游戏必须提供WASD按键小游戏。

#### Scenario: 小游戏成功
- **WHEN** 5个WASD按键在5秒内按顺序完成
- **THEN** 成功钓鱼，闪耀概率+2%，不额外消耗鱼饵

#### Scenario: 普通成功
- **WHEN** 5个WASD按键在30秒内完成
- **THEN** 成功钓鱼，消耗1个鱼饵

#### Scenario: 小游戏失败
- **WHEN** 30秒内未完成按键
- **THEN** 钓鱼失败，鱼脱钩跑了

### Requirement: 打窝系统
游戏必须提供打窝功能缩短上鱼时间。

#### Scenario: 打窝效果
- **WHEN** 用户点击"打窝"按钮
- **THEN** 从总上鱼时间中减少1分钟

#### Scenario: 饵料消耗
- **WHEN** 用户点击打窝
- **THEN** 饵料消耗进度增加：20% → 40% → 60% → 80% → 100%
- **AND** 消耗为空后进入10秒冷却补充阶段

### Requirement: 鱼类系统
游戏必须提供4种大小的鱼。

#### Scenario: 鱼大小顺序
- **WHEN** 鱼按大小分类时
- **THEN** 顺序为：小型 < 中型 < 大型 < 巨型
- **AND** 价格递增：小型最低，巨型最高

#### Scenario: 闪耀属性
- **WHEN** 钓鱼成功时
- **THEN** 计算闪耀概率：基础2% + 幸运饵2% + 奇点竿2% = 最大6%
- **AND** 闪耀鱼售价×5

### Requirement: 商店系统
游戏必须提供商店购买功能。

#### Scenario: 购买鱼竿
- **WHEN** 用户购买鱼竿
- **THEN** 消耗对应金币，已购买的鱼竿可随时切换装备
- **AND** 鱼竿列表：竹竿（初始）、共振钓竿(1000金币)、奇点竿(5000金币，闪耀+2%)

#### Scenario: 购买鱼饵
- **WHEN** 用户购买基础鱼饵
- **THEN** 消耗4金币

### Requirement: 合成系统
游戏必须提供材料合成功能。

#### Scenario: 基础合成
- **WHEN** 合成基础鱼饵
- **THEN** 消耗1个任意材料，获得2个基础鱼饵

### Requirement: 存档管理
游戏必须支持存档操作。

#### Scenario: 导出存档
- **WHEN** 用户点击导出
- **THEN** 生成存档数据并复制到剪贴板

#### Scenario: 导入存档
- **WHEN** 用户粘贴存档数据并确认导入
- **THEN** 覆盖当前存档

#### Scenario: 删除存档
- **WHEN** 用户确认删除
- **THEN** 清除所有存档数据并重置游戏

### Requirement: 图鉴系统
游戏必须记录捕获过的鱼类。

#### Scenario: 记录捕获
- **WHEN** 成功钓到鱼
- **THEN** 在图鉴中记录该鱼类（区分普通版和闪耀版）

### Requirement: 桌面通知
游戏必须支持上钩时发送通知。

#### Scenario: 发送通知
- **WHEN** 鱼上钩时
- **THEN** 如果浏览器允许，发送桌面通知提醒

### Requirement: 鱼篓堆叠
游戏必须提供鱼篓管理功能。

#### Scenario: 自动堆叠
- **WHEN** 渔获放入鱼篓
- **THEN** 相同属性（大小、闪耀、类型）的鱼自动堆叠显示

### Requirement: 调试模式
游戏必须支持调试功能。

#### Scenario: 开启调试
- **WHEN** URL包含 ?debug 参数
- **THEN** 显示调试按钮，点击可立即上钩

## 数据配置要求
所有数值、概率、配方统一存放在 gameData.json 文件中：
- 鱼类属性和价格
- 水域配置和概率
- 鱼竿和鱼饵属性
- 随机事件配置
- 钓鱼等级概率表
